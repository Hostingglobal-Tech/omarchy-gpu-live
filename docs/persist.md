# 영구 저장 - 저장한 것이 재부팅에 남게 한다

## 왜 필요한가

라이브 USB 는 읽기 전용이다. 그래서 쓰기가 전부 **RAM 에 얹힌 임시 공간**으로 간다.
두 가지가 동시에 걸린다 - 용량이 좁고(기본 256MB, 우리는 8GB 로 늘렸다),
**재부팅하면 통째로 사라진다.** OS 업데이트를 해도 남지 않는 이유가 이것이다.

USB 에 저장 영역을 하나 준비해 두면 그것을 쓰기 계층으로 쓴다. 그러면
업데이트도 설정도 만든 파일도 남고, 용량은 RAM 이 아니라 **USB 크기만큼**이다.

## 준비물

USB 안에 라벨이 `AIOSDATA` 인 ext4 저장 영역 하나.
라벨이 정확해야 한다 - 부팅 메뉴가 그 이름으로 찾는다.

### Ventoy 를 쓰는 경우 (권장)

Ventoy 는 USB 앞쪽만 쓰고 뒤를 비워 둘 수 있다.

1. Ventoy 를 설치할 때 **보존 공간(Preserve space)** 을 잡는다.
   64GB USB 라면 20GB 정도가 넉넉하다
2. 그 빈 자리에 ext4 저장 영역을 만들고 라벨을 `AIOSDATA` 로 준다.
   리눅스의 디스크 관리 도구(디스크 유틸리티 등)에서 파일시스템을 ext4 로 고르고
   라벨 칸에 `AIOSDATA` 를 적으면 된다
3. Windows 에서 만들었다면 라이브로 한 번 부팅해 리눅스에서 라벨을 확인한다

### ISO 를 직접 구운 경우

구운 뒤 USB 뒤쪽이 빈 채로 남는다. 그 자리에 같은 방식으로 만든다.

라벨만 나중에 바꾸려면 리눅스에서 `e2label <장치> AIOSDATA`.

## 쓰는 법

부팅 메뉴에서 **"... - 영구 저장(USB 에 남긴다)"** 항목을 고른다.
기본 항목은 그대로 RAM 을 쓴다 - 저장 영역이 없는 USB 에서도 부팅되게 남겨 둔 것이다.

## 걸렸는지 확인

부팅 후:

    findmnt /run/archiso/cowspace

소스가 `/dev/...` 로 나오면 영구 저장이 걸린 것이다. `tmpfs` 면 RAM 을 쓰고 있다.
용량은 `df -h /run/archiso/cowspace` 로 본다.

## 주의

- **저장 영역이 없으면 그 메뉴로 부팅이 실패한다.** 그럴 때는 기본 항목으로 부팅하라.
- 라벨은 정확히 `AIOSDATA`. 대소문자를 가린다.
- ext4 로 만들어라. FAT32 는 리눅스 권한을 못 담아 오버레이가 깨진다.
- 영구 저장을 쓰면 그 USB 가 그 기계의 상태를 갖는다 - 여러 기계를 오갈 때는
  기본(RAM) 항목이 더 깨끗하다.
